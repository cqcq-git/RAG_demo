# RAG Example with Python

This project demonstrates a Retrieval-Augmented Generation (RAG) system implemented in Python. It uses modern NLP techniques to answer questions about documents by retrieving relevant information and generating coherent responses.

## Features

- **FastAPI chatbot API** via `app.py`
- **Chainlit chat UI** via `ui.py`
- **Hybrid retrieval**: dense vector search (ChromaDB) + BM25 keyword search
- **Text embedding** using `BAAI/bge-large-en-v1.5` via `sentence-transformers`
- **Reranking** using `cross-encoder/ms-marco-MiniLM-L12-v2`
- **Vector database** using ChromaDB (persisted to `./chroma_storage`)
- **Answer generation** with Google Gemini (`gemini-2.0-flash`) or a local model via Ollama (`qwen3:4b`), selected by the `LLM_MODE` environment variable

## Dependencies

The project uses the following key packages:

- `chainlit`: Interactive chat UI
- `fastapi` + `uvicorn`: Web API framework and ASGI server
- `sentence-transformers`: Embedding and cross-encoder reranking
- `chromadb`: Vector database
- `rank-bm25`: BM25 keyword retrieval
- `google-genai`: Gemini integration
- `ollama`: Local model client
- `python-dotenv`: Environment variable loading

## Installation

1. Ensure you have Python 3.12 or higher installed.
2. Install [`uv`](https://github.com/astral-sh/uv) for dependency management if needed.
3. From the project root, install dependencies:
   ```bash
   uv sync
   ```
4. Create a `.env` file in the project root. Set `LLM_MODE` to either `gemini` or `ollama`:
   ```env
   LLM_MODE=ollama
   # Required only when LLM_MODE=gemini
   GEMINI_API_KEY=your_api_key_here
   ```
5. If using local models, install [Ollama](https://ollama.com/download) and pull the model:
   ```bash
   ollama pull qwen3:4b
   ```
   Make sure the Ollama daemon is running before starting the app — either launch the Ollama desktop app, or run:
   ```bash
   ollama serve
   ```

## Usage

### Run the FastAPI chatbot API

Start the API server with:
```bash
uv run uvicorn app:app --reload
```

Then send POST requests to `POST /ask`:

```json
{
  "prompt": "What is this project about?",
  "top_k": 5
}
```

The API returns an answer and the retrieved source chunks.

### Run the Chainlit chat UI

Start the interactive UI with:
```bash
uv run chainlit run ui.py -w
```

Open the URL shown by Chainlit in your browser to chat with the RAG demo. Responses are generated by either Google Gemini or a local Ollama model based on the `LLM_MODE` environment variable.

## Troubleshooting

- **`Ollama Error: Failed to connect to Ollama`** — the Ollama daemon is not running. Start the Ollama desktop app or run `ollama serve` in another terminal.
- **Model not found in Ollama** — run `ollama pull qwen3:4b`.
- **First-run model download** — `app.py` loads embedding and reranker models with `local_files_only=True`. If you see a "model not found" error from `sentence-transformers`, the Hugging Face cache is missing. Either pre-download the models, or temporarily set `local_files_only=False` in `app.py` for the first run.

## App Behavior

- `app.py` loads the embedding and reranking models at startup.
- It automatically ingests `doc.md` into ChromaDB if the collection is empty, and builds an in-memory BM25 index over the same chunks.
- `get_answer()` runs hybrid retrieval (vector + BM25), deduplicates, reranks the combined set, and generates an answer using either Gemini or Ollama based on `LLM_MODE`.
- `ui.py` uses Chainlit to provide a chat interface and displays source chunks alongside answers.

## Project Structure

- `app.py`: FastAPI application with hybrid RAG inference and `/ask` endpoint
- `ui.py`: Chainlit chat UI that calls `get_answer()` from `app.py`
- `main.ipynb`: Notebook walkthrough of the RAG pipeline
- `doc.md`: Document content used for ingestion
- `chroma_storage/`: Persistent ChromaDB storage (auto-created)
- `pyproject.toml`: Project configuration and dependencies
- `README.md`: This file
